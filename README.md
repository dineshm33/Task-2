# ELEVATE-SDE-Task-2 — CredVault Frontend

Frontend-only prototype using React, Vite and browser localStorage dummy data.

## Run
1. Install Node.js 18+.
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL printed by Vite.

- Password: `admin`

`/`, `/request`, `/track`, `/verify`, `/admin/login`, `/admin/applications`, `/admin/certificates`.
